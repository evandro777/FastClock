FastClock

Alarms, a timer, a stopwatch and a Pomodoro. Light and fast, and it keeps ringing from the tray.

GitHub · Releases

Early version. Tested on Linux Mint Cinnamon (X11).

What it does

A clock for the desktop that stays out of the way. Written in Rust with Slint, software rendering only, no async runtime.

AlarmsRepeat on chosen days or ring once. Snooze or Stop from the window or the notification.
TimerSet it with the steppers or a quick choice (1 to 30 min). The time shows in the window title.
StopwatchTenths of a second, steady digits that do not jump.
PomodoroWork and break rounds with a long break after four.
TrayClose the window and alarms keep working. Optional start at login.
LightSmall binary and little memory.

Install with Flatpak (updates itself)

This remote keeps FastClock updated with flatpak update and your software centre:

flatpak remote-add --system --if-not-exists fastclock https://evandro777.github.io/FastClock/fastclock.flatpakrepo
flatpak install --system fastclock io.github.evandro777.FastClock

Use --system: Linux Mint's Update Manager only looks at system-wide Flatpaks. The runtime comes from Flathub. The remote is GPG-signed, but the key lives in the source repository, so it is only as trustworthy as that.

Or the AppImage

Download FastClock-<version>-x86_64.AppImage from the latest release, chmod +x it and run it. It uses the fontconfig, xkbcommon and X11 libraries already on your system, and carries update information, so AppImageUpdate, Gear Lever or AppManager download only what changed.

Run one of the two, not both: they use different data folders.
